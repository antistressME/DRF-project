# Проект интернет-магазина
Платформа для онлайн-обучения.

Проект LMS-системы, в которой каждый желающий может размещать свои полезные материалы или курсы.

### Установка

Проект написан с использованием Django.
Чтобы установить проект, нужно сначала настроить виртуальное окружение, 
а почте скопировать проект из репозитория в GitHub, для этого используйте:
` git clone https://github.com/antistressME/DRF-project.git `

### Использование

Проект обрабарывает API запросы и возвращает ответ в формате JSON.

### Структура проекта

В проекте реализованы приложения lms, user, payments.
Добавлена группа модераторов, которая имеет возможность
работы с любыми уроками и курсами, но без возможности их удалять и создавать новые. 

##### В приложении *lms* реализованы классы *Lesson (Урок)* и *Course(Курс)*.

Класс **Курс** включает поля:
- название,
- превью (картинка),
- описание,
- владелец.

Класс **Урок** включает поля:
- название,
- описание,
- превью (картинка),
- ссылка на видео,
- владелец.

Урок и курс - это связанные между собой классы. 
Уроки складываются в курс, в одном курсе может быть много уроков.

При создании урока или курса поле владельца заполняется автоматически, 
создать урок или курс может только авторизованный пользователь.

Неавторизованный пользователь может только просматривать список курсов или уроков.

Посмотреть детальную информацию по уроку или курсу, а также изменять и удалять их
может владелец.

##### В приложении *users* реализованы классы *User (Пользователь)*.

Класс **Пользователя** включает поля:
- все поля от обычного пользователя, но авторизация заменена на email;
- телефон;
- город;
- аватарка.

Для пользователей настроена JWT-авторизация.

##### В приложении *payments* реализован класс *Payment (Платежи)*.

Класс **Платежи** включает поля:

- пользователь, связанное с моделью User (Пользователь);
- дата оплаты,
- оплаченный курс, связанное с моделью Course(Курс);
- оплаченный урок, связанное с моделью Lesson (Урок;
- сумма оплаты,
- способ оплаты: наличные или перевод на счет.

Для класса платежей настроена фильтрация для эндпоинта вывода списка платежей с возможностями:

- менять порядок сортировки по дате оплаты,
- фильтровать по курсу или уроку,
- фильтровать по способу оплаты.
